Key Takeaways for Decision Makers

  • Underwriting Standard: Always use Median Rent ($Q_2$) rather than Mean Rent when projecting cash flows, as high-end outliers distort averages.
  • Marketing & Listing Strategy: Modal values ($3,500 in Manhattan, $2,800 in Brooklyn, $2,200 in Queens) reflect psychological pricing thresholds used by listing portals.
  • R Programming Insight: Avoid Base R's built-in mode() function as it returns variable storage type rather than statistical mode. Use DescTools::Mode().
