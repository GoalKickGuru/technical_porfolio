Extended materials from "Exploratory Data Analysis with Python Cookbook" (Packt).

  scripts/data_preparation.py, run_data_preparation.py

Quick start
-----------

Requirements: Python 3.8+, pandas, numpy (scipy for Ch.1 mode)
